# ankata-site
Static site for https://ankata.app (Ankata delivery app, Bamako), served by GitHub Pages from `main`, root folder. Plain HTML + `style.css`: no JavaScript, no external resources.
`confidentialite/index.html` is the source of truth for the Ankata privacy policy.
`supprimer-compte/index.html` describes the in-app path « Paramètres » → « Supprimer mon compte »: any app UI change to that path must ship together with the matching change here (same commit when possible).
